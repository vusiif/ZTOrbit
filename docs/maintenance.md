# 维护约定

## 中转站关联的部署假设

网络与 Moon 的关联按同一服务器部署设计：网络由该服务器的 ztncui 创建，Moon 由该服务器的 ZeroTier 创建并签名。这是关联机制的适用前提，不代表任意网络与 Moon 都存在对应关系；更换控制端或采用跨服务器部署时，需要重新确认此假设。

网络授权仍由控制端管理，分发中转站配置不替代授权。

## 发行包边界

正式发行包只包含主程序及运行依赖，测试辅助程序和测试数据不随包发布，避免模拟 CLI 被误当作真实服务工具。

macOS 的实机验证与正式分发要求见 [macOS 文档](macos.md)。

## 验证记录

`0.2.2` 已完成 Windows x64 Release 构建、36 项 GUI 回归测试、独立 API SDK 引用验证，以及插件开发 SKILL 示例编译。

回归测试使用模拟 CLI 和临时环境，其通过结果不代表真实 ZeroTier 服务安装、卸载或系统授权流程已经通过实机验证。Apple Silicon macOS 尚未完成实机验证。
