# 网络部署与默认连接约定

本文是本项目网络部署与默认连接行为的统一约定。客户端与服务端的服务器定位、网络与 Moon 关联、成员查询及中转连接均以本文为依据；其他文档引用本文，不单独维护另一套部署规则。

**本项目只对符合本文约定的部署负责。约定之外的设置及其造成的连接失败、功能异常和兼容问题，一概由部署者自行负责；本项目不提供相应的适配、兼容或排障保证。** 工具能够接受某个参数、协议能够表示某种地址，或测试提供覆盖入口，均不代表该部署属于支持范围。

## 同一服务器与 ID 对应关系

网络由服务器上的 ztncui 管理本机 ZeroTier 控制器创建，Moon 由该服务器的 ZeroTier 节点创建并签名；该服务器同时运行 ZTOrbitHub 与 Pylon `reflect`。本文中的“房间”指 ztncui 创建的 ZeroTier 网络，与语音、桌面共享插件中的业务房间分别定义。

所有 ID 使用十六进制表示，关联规则如下：

| 标识 | 长度 | 约定 |
| --- | --- | --- |
| 服务器 ZTID | 10 位 | 服务器 ZeroTier 节点 ID，也是本机网络控制器的节点 ID |
| 网络 ID | 16 位 | 前 10 位等于服务器 ZTID，后 6 位区分该控制器创建的网络 |
| 服务器 Moon ID | 16 位 | `000000` 加服务器 ZTID，后 10 位等于服务器 ZTID |

因此：`网络 ID 前 10 位 = 服务器 ZTID = 服务器 Moon ID 后 10 位`。例如：

```text
服务器 ZTID： a1b2c3d4e
网络 ID：     a1b2c3d4e123456
服务器 Moon ID：000000a1b2c3d4e
Moon 文件名： 000000a1b2c3d4e.moon
```

客户端按该关系关联网络与 Moon。外部控制器创建的网络、不同服务器提供的 Moon，以及不满足上述 ID 关系的组合，均不属于本项目支持的部署。

## 服务器端口与连接地址

| 服务 | 约定端口 | 连接地址与用途 |
| --- | --- | --- |
| ZeroTier / Moon | `9993/UDP` | 服务器公网 IPv4；Moon 的 `stableEndpoints` 使用 `服务器公网IPv4/9993` |
| ZTOrbitHub | `18100/TCP` 和 `18100/UDP` | 各 ZeroTier 网络内服务器固定虚拟 IP `.1`；用于查询、控制及应用数据转发 |
| Pylon `reflect` | `9443/TCP` | 同一服务器公网 IPv4；Docker 宿主机 `9443/TCP` 映射容器 `443/TCP`，用于 ZeroTier TCP 回退 |

客户端的 TCP 回退中继端点按 `服务器公网IPv4/9443` 配置。ZTOrbitHub 的端点按所在网络的 `.1:18100` 确定。部署时应保证相应防火墙与安全组允许这些连接。

ZeroTier 的 `local.conf` 中 `settings.tcpFallbackRelay` 使用原生 `IP/9443`；界面与 `.z2bundle` 配置包使用 `IP:9443`。候选网络的服务器 IPv4 只取该网络对应 Moon 服务器根节点的 `stableEndpoints`，并按上面的 ID 关系校验；不得使用虚拟网段 `.1`、客户端 IP 或任意 peer 地址。端口固定为 `9443/TCP`，不使用 Moon 的 `9993/UDP`。具体读写、开关和导入导出规则见[本机 ZeroTier TCP 回退配置](local-config.md)。

ZeroTier 本地管理 API 使用服务器回环地址 `127.0.0.1:9993/TCP`，与公网 `9993/UDP` 的数据通信分开；它不是 Pylon 的监听端口。

更改上述端口、将服务拆分到其他服务器或使用不同连接地址，均属于约定之外的设置。

## ztncui 网络与服务器固定地址

在 ztncui 创建的每个 ZeroTier 网络必须使用 IPv4 `/24` 网段，子网掩码为 `255.255.255.0`。例如网络为 `12.34.56.0/24` 时：

1. 服务器本机 ZeroTier 必须加入该网络，并在控制器中获得授权。
2. 在 ztncui 中将服务器成员的虚拟 IPv4 固定分配为 `12.34.56.1`，前缀长度为 `/24`；地址池与其他成员不得占用该地址。
3. ZTOrbitHub 必须能在该固定虚拟地址上通过 `18100/TCP` 和 `18100/UDP` 提供服务。

服务器加入多个网络时，每个网络都分别满足以上要求。网络授权由控制器管理，导入或分发 Moon 配置不替代入网与授权。

客户端按本机在该网络中的虚拟 IPv4 保留前三段、将最后一段改为 `1`，定位服务器。例如 `12.34.56.23/24` 对应服务器 `12.34.56.1:18100`；不会根据服务器普通成员地址或其他网段布局重新猜测。

非 `/24` 网段、服务器未加入或未授权、服务器地址不是固定 `.1`，均属于约定之外的设置。
