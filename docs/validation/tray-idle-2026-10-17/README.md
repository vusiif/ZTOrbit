# 托盘待机轮询优化验证（2026-10-17）

环境：Windows x64、MSVC 2022、动态 Qt 6.8.3，Release，原生 windows 平台。应用版本保持 0.4.1，公开 API 保持 0.4。

## 行为与边界

隐藏到托盘和最小化均停止界面 JsonPoller、服务状态定时器与成员刷新定时器，并取消未完成的 CLI 进程、成员请求和 ICMP ping；恢复窗口立即重新查询。保留上次数据、备注与展开状态。用户已启动的安装／服务操作继续完成。

插件网络服务按在途请求和有效订阅创建使用期。首次使用先等待本机 ID 与网络快照，初始化最长等待 6.5 秒后通过正常传输错误回调结束不可用网络请求；最后一个使用期结束时释放轮询、网络线程、UDP 套接字、中转维护及其在途请求。取消订阅即释放使用期，不必等订阅对象销毁。配置未变时避免重复配置工作线程。持续订阅独立于窗口可见性，语音实现未改动。

## 验证结果

- [界面回归](ui.txt)：7 通过，0 失败，含初始化与清理。隐藏后观察 2.2 秒无新增 CLI 查询、无周期 stateChanged；最小化后观察 1.2 秒无新增 CLI 查询；恢复后获得新数据。覆盖原生标题栏关闭到托盘及恢复、在途成员请求取消、ICMP 进程销毁、展开状态保留、服务离线防抖和查询超时单次计数。
- [网络与取消回归](network.txt)：6 通过，0 失败，含初始化与清理。无使用者时无 CLI 查询；最后使用者释放后观察 1.3 秒无新增查询；多个订阅中取消一个后另一个继续维持轮询；HostServices 请求完成／停止后释放使用期；使用真实本地 TCP 控制回复与 UDP 数据包验证订阅接收，取消后可以重新绑定原接收端口；慢查询暂停后立即恢复成功且不误报失败。
- 查询超时恢复测试允许已经在途的旧慢请求走完五秒截止时间，加下一次一秒轮询；保留原有 11.5 秒内不提前报告失败的断言。暂停取消与真实超时分别处理，取消不计入离线失败。
- 未测量固定 CPU 降幅，不将零新增查询或端口释放换算为百分比。macOS 服务监控同步接入可见性控制，但没有原生 macOS 验证。本轮没有修改共享网络实现或 Linux 服务端。
