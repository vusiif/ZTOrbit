# 插件运行依赖分离证据（2026-10-14）

> 历史证据：本轮验证对应应用 0.3.3／API 0.3 的 v2 运行依赖分离。当时媒体与语音运行库进入主进程并保留到进程退出；2026-10-15 起媒体改为独立工作进程，本目录数据不代表当前行为。当前交付契约见[插件运行依赖交付](../../plugin-runtime-separation.md)，迁移后的实测证据见[插件服务迁移验证](../plugin-services-2026-10-15/README.md)。

- `artifacts.json`：本轮 `dist/` 产物的字节数与 SHA-256，包括 Windows 主程序、两端 API 0.3 SDK、Linux 服务端包和两端语音插件。
- `audio.csv`：物理采集／静音回送的 22 轮加载／卸载记录，列含每轮私有提交、工作集、残留运行库目录与句柄数。第 0、1 轮为暖机。
- `idle.csv`：空闲场景的 22 轮记录，另含线程数，用于核对逐轮增长。
- `memory.png`：同一轮次的私有内存曲线，分“页面／设备枚举”和“物理采集／静音回送”两组。

原始文件名带日期后缀（`plugin-runtime-{artifacts,audio,idle,memory}-2026-10-14.*`），归档时移入本目录并去掉后缀；内容未改写。结论、计数与哈希以这些原始文件为准，不能用于推断当前 worker 进程的内存或模块残留。
