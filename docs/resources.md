# 资源占用分析

2026-10-13，Windows 11 x64、Qt 6.8.3、AMD Radeon 760M，使用Release生产程序和干净解压的运行包。每种场景运行2次，启动后6秒取样，收起到托盘后1.5秒再取样，表中为中位数。相邻的模拟CLI通过独立PATH和查询日志验证确实被调用；不会安装、卸载、加入或退出真实ZeroTier网络。

私有提交是进程独占的已提交虚拟内存，工作集是当时驻留的物理页，包含共享DLL等；两者不能混用，也不代表显卡的专用显存。驱动、DPI、字体和数据量会改变结果。本次数字是受控样本，不是所有机器的保证。原始摘要见 [测量数据](resource-measurements.json)，复测脚本为 `src/tests/ProfileResources.ps1`，仅应对隔离的运行包副本执行，脚本会加入测试CLI及日志。

约19.68 MiB来自未使用的Mesa OpenGL软件库；其他收益来自多套控件样式／素材、多语言Qt翻译和QML调试插件。宿主已固定使用Basic，默认保留英文、简体中文和繁体中文Qt翻译。保留D3D编译器、Widgets原生托盘后备、音频、Multimedia及FFmpeg；SDK及应用版本保持原值，语音DLL未重编。

Windows默认D3D11和Qt的CPU场景图均不需要 `opengl32sw.dll`。需要显式OpenGL软件渲染兼容环境时用 `-IncludeOpenGLSoftware` 打包；第三方QML插件明确导入其他Controls样式时用 `-KeepAllQmlStyles`。插件自己的其他QML／图形／编解码依赖仍应按其要求部署。

## 内存

下表为私有提交，单位MiB；“少量数据”为2个网络、4个peer，“大表”为40个网络、35个peer。语音场景只加载并初始化现有DLL，没有入房或录音。

| 场景 | 优化前GPU | 优化后GPU | 优化后低内存模式 |
| --- | ---: | ---: | ---: |
| 空列表，显示窗口 | 102.97 | 96.00 | 55.86 |
| 少量数据，显示窗口 | 107.31 | 102.84 | 56.82 |
| 少量数据，托盘驻留 | 112.88 | 86.91 | 63.16 |
| 大表，显示窗口 | 140.62 | 115.34 | 68.96 |
| 大表，托盘驻留 | 146.06 | 98.10 | 75.28 |
| 少量数据及语音初始化，显示窗口 | 129.48 | 121.07 | 80.09 |
| 少量数据及语音初始化，托盘驻留 | 135.78 | 105.02 | 86.31 |

少量数据正常窗口的工作集分别为154.82、146.33、110.93 MiB；大表分别为184.56、159.78、122.96 MiB。语音预初始化增加约20 MiB私有提交，其设备查询、线程准备和FFmpeg依赖保留。

主要实现：启动时不创建14个关闭的弹窗／文件选择器；每行的菜单及备注编辑器按需创建，结束编辑后释放编辑器；成员子模型延迟分配；隐藏窗口时释放可重建的场景图、交换链、纹理等资源。恢复窗口会重新构建图形资源，因此更重视驻留内存而非保持渲染缓存。列表、展开状态、输入和语音会话继续保留。Qt运行时、字体和渲染驱动仍占据固定基础内存。

资源释放采用Qt公开的场景图／图形资源持久化设置，说明见 [QQuickWindow资源管理](https://doc.qt.io/qt-6.8/qquickwindow.html#resource-management)；静态Basic导入的依据见 [Qt控件样式选择](https://doc.qt.io/qt-6.8/qtquickcontrols-styles.html#compile-time-style-selection)。

设置中的“禁止GPU加速”默认关闭；开启后使用CPU绘制，保存选择并在完全退出、重新启动后生效。也可仅对本次启动强制禁用GPU加速：

```powershell
.\ZTGUI.exe --disable-gpu-acceleration
```

须先通过退出操作结束已有进程；标题栏关闭只收起到托盘，第二次启动会激活旧进程，不能切换渲染器。启动参数不改写保存的设置，使用该参数时界面开关显示开启且不可修改，并说明由启动参数强制禁用。CPU绘制适合当前以文本、表格和基本控件为主的管理界面。复杂动画、视频或自定义Shader插件需要另行评估，依赖GPU的插件使用默认模式。本次没有测量滚动帧率或CPU峰值，不能据此声称软件模式更快。
